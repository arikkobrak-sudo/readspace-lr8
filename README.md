# ReadSpace

Адаптивний лендинг читацького клубу ReadSpace. Сайт містить добірку книжок, інформацію про клуб, відео та мапу.

## Локальний перегляд

Відкрийте `index.html` у браузері. Для відео, мапи та віджета погоди потрібен доступ до Інтернету.

## Публікація

Для GitHub Pages використовується корінь гілки `main`. Для Netlify каталог публікації — корінь репозиторію, команда збирання не потрібна.
